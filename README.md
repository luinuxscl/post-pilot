# PostPilot

Automatiza la creación de contenido con agentes escritores inteligentes en Laravel.

## Instalación

```bash
composer require luinuxscl/post-pilot
```

## Configuración

Publica el archivo de configuración:

```bash
php artisan vendor:publish --tag=postpilot-config
```
